# Language Models 🗣️

## 🎯 Learning Objectives
- Understand statistical language modeling principles
- Build vocabulary and language models from scratch
- Learn spell correction and edit distance algorithms
- Handle out-of-vocabulary words effectively

## 📖 Content Overview

### 1. **Vocabulary Model Building**
- `01_building_vocabulary_model.ipynb` - Core vocabulary construction
- Learn word frequency analysis and filtering
- Understand vocabulary size vs performance trade-offs

### 2. **Spell Correction Systems**
- `02_spell_correction_candidates.ipynb` - Edit distance and candidates
- Implement edit distance algorithms
- Generate and rank correction candidates

### 3. **Language Model Construction**
- `03_building_language_model.ipynb` - N-gram language models
- Statistical modeling of text sequences
- Probability estimation and smoothing
- Model evaluation and perplexity

### 4. **Out-of-Vocabulary Handling**
- `04_out_of_vocabulary_handling.ipynb` - OOV word strategies
- Unknown word modeling techniques
- Subword tokenization approaches
- Model robustness improvements

## 🛠 Prerequisites
- Completed: **01-04** (especially 02_Basic_NLP_Concepts)
- Understanding of probability and statistics
- Knowledge of text preprocessing techniques
- Basic familiarity with n-grams
