# SpaceX Falcon 9 Data Science Project: A Progressive Story

Welcome to my personal, end-to-end data science project exploring SpaceX Falcon 9 launches. This repository is organized as a narrative journey through real-world data science, from raw data collection to actionable insights and interactive dashboards.


## Why SpaceX Falcon 9?

SpaceX’s Falcon 9 program is a symbol of innovation and data-driven engineering. I chose this topic to challenge myself with real-world, complex data and to build a portfolio project that demonstrates the full data science lifecycle.


## Project Narrative & Structure

Follow my journey as each notebook builds on the last, creating a seamless, reproducible workflow:

| Stage | Notebook/Script | Purpose |
|-------|-----------------|---------|
| 1. Web Scraping & Data Collection | `spacex-falcon9-webscraping.ipynb` | Gather launch records from Wikipedia and SpaceX APIs |
| 2. Data Wrangling & Cleaning | `spacex-falcon9-data-collection-api.ipynb` | Prepare and clean the raw data for analysis |
| 3. SQL Analysis & Feature Engineering | `spacex-falcon9-sql-analysis.ipynb` | Explore, aggregate, and transform the data for deeper insights |
| 4. Geospatial Analysis & Mapping | `spacex-launch-site-location-analysis.ipynb` | Visualize and analyze launch site locations and their impact |
| 5. Exploratory Data Analysis (EDA) | `spacex-falcon9-eda-dataviz.ipynb` | Visualize trends and patterns in the data |
| 6. Machine Learning & Prediction | `spacex-machine-learning-prediction.ipynb` | Build, tune, and compare models to predict landing outcomes |
| 7. Dashboarding & Communication | `spacex-launch-dashboard-app.py` | Present findings with interactive dashboards and clear visualizations |

Each notebook builds on the previous, creating a seamless, reproducible workflow that mirrors a real-world data science project.
